# Gym Manager

## About the Project

Gym Manager is a simple Python program made to manage gym members.

This project is made for beginners who are learning Python. It uses basic concepts like lists, dictionaries, loops, if-else statements and user input.

## Features

The program can:

* Add a new gym member
* View all members
* Search for a member
* Delete a member
* Exit the program

## Information Stored

For every member, the program stores:

* Name
* Age
* Membership plan

## How to Run

1. Install Python on your computer.
2. Save the program as `main.py`.
3. Open the terminal or command prompt.
4. Run:

```bash
python main.py
```

5. Choose an option from the menu.

## Example

```text
GYM MANAGER
1. Add Member
2. View Members

4. Delete Member
5. Exit

Enter choice:
```
