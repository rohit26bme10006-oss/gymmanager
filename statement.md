# Project Statement

## Project Name

Gym Manager

## Problem Statement

Managing gym members manually can become difficult when there are many members. It can take time to find a particular member or remove an old member.

The Gym Manager project is made to solve this problem in a simple way using Python.

## Objective

The main objective of this project is to create a small program that can manage basic gym member information.

The user can add members, view the members, search for a member and delete a member.

## Working of the Project

When the program starts, it shows a menu with different options.

The user can select:

1. Add Member
2. View Members
3. Search Member
4. Delete Member
5. Exit

When a member is added, the program takes the member's name, age and membership plan and stores them in a list.

The search option checks the names of the members and displays the details if the member is found.

The delete option removes the selected member from the list.

## Concepts Used

The project uses basic Python concepts such as:

* Lists
* Dictionaries
* Loops
* Conditional statements
* User input
* String functions

## Conclusion

This project helped me understand how lists and dictionaries can be used together to store information. It also helped me practice loops, conditions and taking input from the user.

The project is simple and can be improved later by adding features such as saving members to a file, updating member details and adding membership fees.
